---

## 如何打开

任选其一：

### 方式 A：直接打开（最简单）

用浏览器打开本目录下的 `index.html` 即可。

### 方式 B：本地静态服务（推荐）

在项目目录执行：

```bash
cd lifeafter-fan-demo   # 或你的克隆目录
python3 -m http.server 8080
```

浏览器访问：`http://127.0.0.1:8080/`

（也可用 `npx serve .` 等任意静态服务器。）

## 操作说明

| 按键 | 作用 |
|------|------|
| `WASD` / 方向键 | 移动 |
| `E` | 采集附近木材 / 石材 / 废料 |
| `B` | 打开 / 关闭建造菜单 |
| 鼠标点击画布 | 在建造模式下放置建筑 |
| `C` | 靠近工作台后打开制作菜单 |
| `空格` | 近战攻击威胁斑块 |
| `1` | 使用背包中的绷带回血 |

右侧面板可查看背包、生命、昼夜状态。

---

## 玩法循环（S1 MVP）

1. 在小地图上走动，靠近资源按 `E` 采集。  
2. 按 `B` 花费材料建造：木屋庇护所、简易工作台、木墙。  
3. 靠近工作台按 `C` 制作绷带 / 火把 / 木矛。  
4. 日落后天色变暗，威胁斑块更凶；火把提升夜间体感，木屋可缓冲伤害。
